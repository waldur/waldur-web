Ansible collections

Waldur’s Ansible collections on Ansible Galaxy provide modules for organizations, projects, marketplace orders and OpenStack resources, so playbooks can manage Waldur alongside the rest of an infrastructure. The modules are generated from Waldur’s API schema and released with each Waldur version.
Documentation
SDKs

SDKs for Python, TypeScript and Go

Waldur’s API clients for Python, TypeScript and Go are generated from its OpenAPI schema and published with every release: waldur-api-client on PyPI, waldur-js-client on npm and go-client on GitHub. Waldur’s own web interface is built on the TypeScript client.
Documentation

Terraform provider

The Waldur provider in the Terraform Registry manages Waldur as code: projects and users, and marketplace resources such as OpenStack tenants, networks and virtual machines. Resources are ordered from marketplace offerings and plans, so approvals, quotas and billing apply as they do in the portal.
Documentation
waldur-cli

waldur-cli

waldur-cli is a command-line tool for the Waldur API, built for people at a terminal as well as for scripts and AI agents, with machine-readable output. It covers OpenStack tenants, instances, volumes and networks; organizations, projects, users and roles; ordering from the marketplace; and the user’s own access tokens and SSH keys.
