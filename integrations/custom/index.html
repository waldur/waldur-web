Waldur Custom Scripts

Waldur provides a mechanism for custom scripts handling resource lifecycle events: provisioning, updates, termination and periodic checks. Scripts run in user-defined container environments, allowing quick integration of services not covered by built-in plugins. Common examples include VPNaaS, Remote Desktop solutions and other bespoke service offerings.
